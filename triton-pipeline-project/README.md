# Нагрузочное тестирование ML-пайплайна (BERT + Sentence-Transformer + Qwen-0.5B)

Проект содержит готовый скрипт для локальной конвертации трех легковесных моделей в формат ONNX, построения сложного сквозного асинхронного пайплайна инференса и проведения его стресс-тестирования на GPU. Также в коде автоматизированы вызовы утилиты `perf_analyzer` для NVIDIA Triton Inference Server.

## 🛠️ Требования к системе
* **ОС:** Windows 10/11 или Linux (Ubuntu)
* **GPU:** Видеокарта NVIDIA с поддержкой CUDA
* **Python:** Версия 3.10 - 3.12 (рекомендуется использовать виртуальное окружение `.venv`)

## 🚀 Быстрый запуск

### 1. Клонирование репозитория и подготовка окружения
Откройте терминал в папке проекта и установите необходимые зависимости:
```bash
# Обновление менеджера пакетов
pip install --upgrade pip

# Установка библиотек для конвертации и работы с моделями Hugging Face
pip install optimum[onnxruntime-gpu] transformers tqdm numpys

# Установка ONNX Runtime с прямой поддержкой CUDA-ядер вашей видеокарты
pip install onnxruntime-gpu --extra-index-url https://visualstudio.com
```

### 2. Шаг 1: Скачивание и конвертация моделей в ONNX
Запустите скрипт для экспорта моделей. Он создаст структуру папок `model_repository` и сгенерирует файлы конфигураций `config.pbtxt` для Triton Server:
```bash
python triton-pipeline-project/models_export.py
```
*Убедитесь, что в консоли появилось сообщение `Все модели подготовлены локально!`.*

### 3. Шаг 2: Запуск нагрузочного тестирования
Запустите главный скрипт бенчмарка. Он загрузит все три модели в VRAM видеокарты, запустит асинхронный симулятор параллельных запросов и выполнит интеграционные вызовы для Triton SDK Perf Analyzer:
```bash
python triton-pipeline-project/load_test.py
```

## 📈 Результаты и сценарии тестирования
Скрипт автоматически симулирует нагрузку от **8 одновременных пользователей** (всего 300 запросов) на сквозную цепочку:
`Текст -> [BERT (Классификация) + Sentence-Transformer (Эмбеддинги)] -> Qwen-0.5B (Генерация)`

В конце работы вы увидите сводную таблицу с метриками **Throughput (RPS)** и **Latency (p95/p99)**, а также зарегистрированные системные команды для тестирования изолированных бэкендов в Triton. Detailed-анализ метрик находится в файле `REPORT.md`.
